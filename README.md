# TinyRetroPad_Crinklerless
TinyRetroPad without Crinkler

I ran the build.bat file with the changes mentioned by ompadu from https://github.com/PlummersSoftwareLLC/TinyRetroPad/issues/21

To build this yourself you need masm32 and VS c++ build tools then download the project https://github.com/PlummersSoftwareLLC/TinyRetroPad.  Modify and run the batch file from the Developer console.
